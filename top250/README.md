## 📌 معرفی

این پروژه یک **مجموعه کامل ابزار** برای **خزش (Crawling)**، **استخراج داده**، **ذخیره‌سازی** و **تحلیل آماری** لیست ۲۵۰ فیلم برتر سایت IMDb است. با استفاده از این کدها می‌توانید:

- صفحات فیلم‌ها را به صورت خودکار دانلود کنید (با استفاده از **Selenium**).
- اطلاعات ساختاریافته شامل **عنوان، سال انتشار، رده‌بندی سنی، مدت زمان، ژانر، کارگردانان، نویسندگان، بازیگران اصلی، فروش (گروس) و همچنین امتیاز و تعداد رأی** را از صفحات استخراج کنید.
- داده‌ها را در پایگاه داده **SQLite** با ساختار نرمال‌شده ذخیره کنید.
- **تحلیل‌های آماری** کامل انجام دهید (میانگین، میانه، توزیع، همبستگی، ژانرهای برتر، فیلم‌های برتر و ...).
- **داشبورد تعاملی** در قالب فایل **Excel** با نمودارهای ستونی، دایره‌ای و پراکندگی تولید کنید.

این پروژه برای محققان داده، علاقه‌مندان به سینما، و توسعه‌دهندگانی که به دنبال یک نمونه کار کامل از **Web Scraping + ETL + Data Analysis + Visualization** هستند، بسیار مناسب است.

---

## 🚀 ویژگی‌های کلیدی

- **خزش هوشمند** با مدیریت خطا، تلاش مجدد و کش کردن صفحات دانلود شده (برای جلوگیری از درخواست‌های تکراری).
- **استخراج داده از JSON-LD** (داده‌های ساختاریافته IMDb) و همچنین **Fallback** به المان‌های HTML در صورت عدم وجود JSON.
- **ذخیره‌سازی در SQLite** با جداول:
  - `movies` (اطلاعات اصلی فیلم)
  - `people` (افراد شامل کارگردان، نویسنده، بازیگر)
  - `movie_directors`، `movie_writers`، `movie_stars` (روابط many-to-many)
  - `box_office` (فروش آمریکا/کانادا)
- **تحلیل آماری** شامل:
  - آمار توصیفی (میانگین، میانه، انحراف معیار، min/max) برای امتیاز، تعداد رأی، مدت زمان
  - ۱۰ فیلم برتر از نظر امتیاز
  - توزیع ژانرها (۱۰ ژانر پرتکرار)
  - توزیع امتیاز در بازه‌های مختلف
  - ضریب همبستگی بین امتیاز و تعداد رأی
- **داشبورد اکسل** با ۴ نمودار:
  - ستونی: ۱۰ فیلم برتر
  - ستونی: توزیع امتیاز
  - دایره‌ای: ژانرهای برتر
  - پراکندگی: رابطه امتیاز و تعداد رأی
- **قابلیت استفاده مجدد** – داده‌های استخراج شده در SQLite ذخیره می‌شوند و می‌توان بدون خزش مجدد، تحلیل‌های مختلف را اجرا کرد.

## 🔧 نصب و راه‌اندازی

### ۱. کلون کردن مخزن

```bash
git clone https://github.com/yourusername/imdb-top250-analytics.git
cd imdb-top250-analytics
```

### ۲. ایجاد محیط مجازی (توصیه می‌شود)

```bash
python -m venv venv
source venv/bin/activate   # Linux / Mac
venv\Scripts\activate      # Windows
```

### ۳. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۴. نصب و راه‌اندازی ChromeDriver

این پروژه از **Selenium** برای مرورگر **Chrome** استفاده می‌کند. شما باید ChromeDriver را نصب کرده و مسیر آن را در فایل `utils.py` (کلاس `IMDBPageDownloader`) تنظیم کنید:

```python
service = Service('/usr/bin/chromedriver')  # مسیر صحیح chromedriver را قرار دهید
```

اگر ChromeDriver را در PATH سیستم دارید، می‌توانید از `Service()` بدون آرگومان استفاده کنید، یا از `webdriver_manager` برای مدیریت خودکار کمک بگیرید (پیشنهاد می‌شود).

> **نکته:** می‌توانید با نصب `webdriver-manager` و تغییر کد، مدیریت خودکار را فعال کنید.

### ۵. تهیه فایل ورودی Excel

برای اجرای خزش یا تحلیل، به یک فایل Excel شامل لیست فیلم‌ها نیاز دارید. این فایل باید حداقل شامل دو ستون باشد:

- `imdb_id`: شناسه IMDb (مثلاً `tt0111161`)
- `url`: آدرس کامل صفحه فیلم (مثلاً `https://www.imdb.com/title/tt0111161/`)

یک نمونه فایل `imdb_dashboard.xlsx` در این مخزن موجود است که حاوی داده‌های ۲۵۰ فیلم برتر IMDb است (از یک منبع معتبر جمع‌آوری شده). اگر این فایل را ندارید، می‌توانید خودتان آن را از سایت‌های دیگر دریافت کنید یا از خروجی پروژه‌های مشابه استفاده کنید.

## 🧪 نحوه اجرا

### اجرای تحلیل روی داده‌های موجود (بدون خزش)

اگر فایل `imdb_dashboard.xlsx` در مسیر پروژه وجود داشته باشد، می‌توانید مستقیماً تحلیل را اجرا کنید:

```bash
python main.py
```

این دستور:
1. داده‌ها را از اکسل بارگذاری می‌کند.
2. گزارش آماری کامل را در **کنسول** چاپ می‌کند.
3. یک داشبورد جدید با نام `imdb_dashboard_analyzed.xlsx` در پوشه `output/` (که به‌طور خودکار ساخته می‌شود) ذخیره می‌کند.

### اجرای خزش و استخراج داده (در صورت نیاز)

اگر می‌خواهید صفحات را دوباره از IMDb دانلود کنید و اطلاعات تازه‌ای استخراج کنید، در فایل `main.py` خط زیر را از حالت نظر خارج کنید:

```python
run_crawler("imdb_dashboard.xlsx")
```

سپس دوباره اجرا کنید:

```bash
python main.py
```

> **توجه:** خزش ممکن است به دلیل محدودیت‌های IMDb و نیاز به اتصال اینترنت پایدار، زمان‌بر باشد (حدود ۲۵۰ فیلم، هر کدام حدود ۲-۳ ثانیه). همچنین ممکن است IMDb درخواست‌های متوالی را محدود کند، بنابراین از `time.sleep` بین درخواست‌ها استفاده شده است.

## 📊 خروجی‌های پروژه

### ۱. پایگاه داده SQLite

فایل `data/imdb_movies.db` شامل جداول زیر است:

- **movies**: شناسه، عنوان، سال، رده‌بندی سنی، مدت زمان (دقیقه)، ژانر
- **people**: شناسه و نام افراد
- **movie_directors**, **movie_writers**, **movie_stars**: روابط بین فیلم و افراد
- **box_office**: فروش در آمریکا/کانادا

### ۲. گزارش آماری در کنسول

مثال خروجی:

```
==================================================
📊 گزارش آماری IMDB Top 250
==================================================
تعداد فیلم‌ها....................... 250
میانگین امتیاز...................... 8.21
میانه امتیاز........................ 8.20
انحراف معیار امتیاز................. 0.18
حداقل امتیاز........................ 8.00
حداکثر امتیاز........................ 9.30
میانگین تعداد رأی................... 1,024,567
میانگین مدت زمان (دقیقه)............ 132

🏆 ۱۰ فیلم برتر از نظر امتیاز:
... (جدول)
```

### ۳. داشبورد اکسل

فایل `imdb_dashboard_analyzed.xlsx` شامل دو شیت است:

- **Movies**: داده‌های خام (با فرمت جدول)
- **Dashboard**: شامل ۴ نمودار تعاملی و خلاصه داده‌ها
