## 📌 معرفی

این پروژه یک مجموعه ابزار کامل برای **خزش (Crawling)**، **استخراج داده**، **ذخیره‌سازی** و **تحلیل آماری** لیست ۲۵۰ فیلم برتر IMDB است. با استفاده از این کدها می‌توانید:

- صفحات فیلم‌ها را به صورت خودکار دانلود کنید.
- اطلاعات ساختاریافته (عنوان، امتیاز، تعداد رأی، ژانر، مدت زمان، کارگردانان، بازیگران و...) را استخراج کنید.
- داده‌ها را در پایگاه داده **SQLite** ذخیره کنید.
- **داشبورد تعاملی** در قالب فایل اکسل با نمودارهای مختلف تولید کنید.
- **تحلیل‌های آماری** دقیق روی داده‌ها انجام دهید (میانگین، توزیع، همبستگی، ژانرهای برتر و...).

---

## 🚀 ویژگی‌ها

- **خزش هوشمند** با استفاده از Selenium و مدیریت خطا
- **استخراج داده از JSON-LD** و همچنین Fallback از المان‌های HTML
- **ذخیره‌سازی در SQLite** با جداول نرمال‌شده (فیلم‌ها، افراد، روابط کارگردان/نویسنده/بازیگر، باکس آفیس)
- **تحلیل آماری** شامل:
  - آمار توصیفی امتیاز، تعداد رأی، مدت زمان
  - ۱۰ فیلم برتر از نظر امتیاز
  - توزیع ژانرها
  - توزیع امتیاز در بازه‌ها
  - ضریب همبستگی امتیاز و تعداد رأی
- **تولید داشبورد اکسل** با نمودارهای ستونی، دایره‌ای و پراکندگی
- **قابلیت اجرای مجدد** بدون خزش مجدد (استفاده از داده‌های موجود)
